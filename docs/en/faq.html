Short answers to the questions we hear most often.

Account & data

Do I need an account?No — local mode lets you annotate without signing in; everything stays on this device. For cloud sync, sharing, snapshots, and image upload, register a free account and sign in.
What's the difference between local mode and being signed in?Local mode: no sign-in, data stays on this device, limits match the Free plan, but no cloud sync / sharing / snapshots / image upload. Signed in: your data is backed up to your account, syncs across devices, and all features are on.
Where is my data stored?Locally in your browser first. Once you're signed in, it is additionally backed up to your account and kept identical across devices.
Can others see my annotations?No — unless you explicitly share a document via a link.
How do I move to a new computer?Just sign in on the new machine — your data syncs automatically. (Alternatively, run Export all and import it. See Backup, Import & Export.)
I forgot my password — now what?Click Forgot password? in the sign-in box (or in the re-login prompt) and follow the email verification steps to set a new one. Google-only accounts can use the same flow to set a password for the first time. See Troubleshooting.
What does "clear local data" do?It removes this browser's local copy — the server copy is untouched and syncs back when you sign in again.

Features

Which pages work?Ordinary web pages, local files (including PDFs), and your own documents — but not the browser's own pages.
What are the free plan's limits?The free plan includes every annotation tool, cloud sync, and collaboration, with capacity caps: 50,000 total, 100 new annotations per day, up to 50 per page (5 per type, text highlights not separately capped), 100 MB cloud storage, 3 new documents per day, and 2,000 imports per day. See Plans & Limits for the full comparison.
Can I annotate PDFs?Yes — local and online PDFs are converted to an annotatable page with all tools. See Annotating PDFs.
Do share recipients need the extension?No — they open the link in any browser, on desktop or phone.
Are there keyboard shortcuts?Yes — Alt+number for tools, plus shortcuts for colors, styles, the drawer, and undo. See Keyboard Shortcuts.
Do annotations survive page changes?They are re-applied with several relocating strategies. Very dynamic pages can occasionally defeat them — in that case, re-apply the annotation.
Can I get my annotations out?Yes — the free plan exports to JSON, CSV, and Markdown; Pro adds HTML. You can also keep an incremental Markdown copy. See Backup, Import & Export.
