Annotating PDFs

Highlight, draw, and add notes to PDF files — local or online — with all the tools you already know.

How it works

Open a PDF in the browser — an online file or a local one — and Sagitnote offers to convert it into an annotatable page. Once you confirm, the PDF is rendered into crisp page images with a selectable text layer, and the usual control panel appears.

From that point everything works as usual: select text to highlight, draw arrows and rectangles, place text notes, take region screenshots, add notes and tags. Annotations are stored with the PDF and re-appear the next time you open it.

Local PDF files

For a PDF opened from your disk, the extension needs permission to read local files: when the browser asks, allow access to file URLs for Sagitnote. Alternatively, a file picker lets you choose the PDF manually — handy when automatic reading is blocked.

Good to know

  • Progress — large PDFs show conversion progress with a page counter. If a conversion fails, refresh the page and try again.
  • Titles — online PDFs take their names from the file name. You can rename the page in the Annotation Manager at any time (right-click the page → rename), and your custom name is kept.
  • Already annotated? — reopening a PDF you have annotated before restores your annotations automatically during conversion.
