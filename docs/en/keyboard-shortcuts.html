Keyboard Shortcuts

Every keyboard shortcut in Sagitnote and how to remap them to your own keys.

Default shortcuts

Shortcuts combine a modifier key (Alt by default) with another key. They work while the annotation panel is open on the page.

KeysAction
Alt + 1Arrow
Alt + 2Flag
Alt + 3Image Rectangle
Alt + 4Page Screenshot
Alt + 5Freehand Line
Alt + 6Text Note
Alt + 7Rectangle Frame
Alt + 8Element Mark
Alt + CCycle through the color palette
Alt + SCycle through highlight styles
Alt + AToggle Auto highlighting
Alt + DOpen / close the annotations drawer
Alt + EAnnotation on/off for the whole browser (works without the panel, anytime)
Ctrl / ⌘ + ZUndo the annotation you just created
EscClose dialogs, menus, and the image viewer
ℹ

Shortcuts are ignored while you are typing in an input field, so they never interfere with writing notes or comments.

Remapping keys

Open Settings → Shortcuts to:

  • Change the modifier to Alt, Shift, or Ctrl.
  • Assign your own key to any action (click the field and press the key; Backspace clears it).
  • Reset everything back to the defaults.
