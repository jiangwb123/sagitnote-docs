Screenshots & Image Rectangles

Capture page regions as image annotations, mark pictures with rectangles, and annotate images directly.

Page Screenshot — capture a region

Pick Page Screenshot on the panel and drag a rectangle over any part of the page. Sagitnote captures exactly that region as an image annotation:

  • Taller than the screen? No problem — the page is scrolled and stitched automatically, so tall sections can be captured in one drag.
  • Extension UI is excluded from the capture; your dashed selection disappears before the shot is taken.
  • The capture is stored with the annotation and appears as a thumbnail in the drawer's Annotation Detail and in the Annotation Manager, where you can view it at full size.

Like every annotation, a screenshot can carry a note and tags (hover toolbar → Note), be recolored or deleted, and take part in sync and export. Close the note popup and the pen icon stays next to the capture — click it to reopen the note.

Image Rectangle — mark a picture

Image Rectangle draws a solid rectangle on an image. It is image-bound: hover an image (the cursor turns into a crosshair) and drag inside it. If you click somewhere that is not an image, a hint reminds you to drag on an image.

  • With auto-save images enabled in settings (on by default), Sagitnote stores a local copy of any image you annotate — so the mark stays stable even if the image changes or the site removes it.
  • Border thickness follows the panel's line width; the color follows the palette.

Image annotations — annotate a picture directly

Beyond the rectangle, Sagitnote supports image annotations: hover an image with the Image Rectangle tool and click the pen icon at its corner. The image is registered as an annotation of its own — with an automatic thumbnail — so you can attach a note such as "this chart is wrong" to the whole image, not just a region of it.

The minimum image size for this (100 × 100 px by default) is adjustable in Settings → Image annotation.

Where captures live

  • Locally, captures are stored in the browser and travel with the annotation.
  • Once you are signed in, captures and annotated images can be uploaded to your account's storage so other devices see them too. Without an upload, image data stays on the device where it was created (other devices fall back to the original image URL).
