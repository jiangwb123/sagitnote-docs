Troubleshooting

Quick fixes for the most common situations: annotations not showing, sync pauses, expired logins, and more.

My annotations are not showing on a page

  • Check the master switch — the panel More menu (or the popup) has an Annotation toggle. If it is off, nothing is displayed anywhere.
  • Reload the page — annotations are restored on load. If the page has changed a lot since your visit, Sagitnote tries several strategies to relocate them. Heavily dynamic pages can still defeat it now and then — simply re-apply the missing annotation.
  • Embedded-frame pages — if the page shows a "✎ Select this zone" pill, make sure you activated the zone that contains your annotations.
  • Right page? — annotations belong to the exact page (and zone) where they were created.

Sync is paused or failing

  • Click the sync failures icon in the manager header to see items that could not be uploaded, each with its reason. Retry individually or all at once; discard if you no longer want to upload an item (local data is kept).
  • If the service runs into temporary errors, automatic sync pauses and resumes by itself — a manual Sync now always works and clears the pause.
  • Large snapshots or documents can exceed plan limits; those items stay local until you free up space or upgrade.

Login problems

  • Session expired? A re-login prompt appears on the page; sign in again and you'll pick up where you left off. Tokens normally refresh silently.
  • Forgot your password? Use the Forgot password? link at the bottom of the sign-in box or the re-login prompt — it opens the password-recovery view in a new tab, where an email verification code lets you set a new password. Google-only accounts can set a password for the first time the same way, which adds email sign-in to the account.
  • Switching accounts is blocked while this browser holds another account's local data — clear local data first (Settings → Data management). The server copy is untouched and comes back when you sign in.

Images missing on another device

Image cloud upload is available on both Free and Pro once you are signed in (counted against your cloud storage quota), so annotated images and screenshots travel across devices. When storage runs short and an image cannot be uploaded, it stays on the device that captured it — on other devices the annotation shows the page's original image instead.

PDF conversion failed

Refresh the page and retry. For local files, make sure the extension is allowed to access file URLs, or use the file picker fallback. Very large PDFs take longer — watch the progress counter.
