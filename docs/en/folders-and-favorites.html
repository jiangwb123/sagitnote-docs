Folders & Favorites

Organize annotated pages into folders and sub-folders, and star the pages you return to.

Folders

The sidebar in the Annotation Manager shows your folder tree. Every page you annotate is filed automatically, and folders help you keep things tidy:

  • Create — click the ➕ button in the sidebar header, or right-click a folder to create a sub-folder inside it.
  • Rename / delete — right-click a folder. Deleting a folder never deletes pages: they move to Unclassified and can be filed again.
  • Move pages — open a page's ⋯ menu and choose the target folder, or use batch mode to select several pages and move them at once.
  • Counts — each folder shows how many pages it contains, including its sub-folders.

The page list groups pages by Today / Yesterday / This week / Earlier so recent work is always at the top.

Favorites

  • Star a page from the control panel: More (⋯) → Add to favorites. The menu item becomes Remove from favorites when the page is already starred.
  • Star from the manager: click the ☆ in the page's row.
  • See only favorites: click the ☆ button above the page list.
ℹ

Favorites apply to annotated web pages. Documents and snapshots are organized through folders instead.
