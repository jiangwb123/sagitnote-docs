Sharing Links

Share a document's annotations with a link: permissions, passwords, expiry, and managing who has access.

What can be shared

Sharing works on your own documents and document snapshots — pages whose annotations are worth passing on to someone else. Ordinary web pages stay private: their annotations stay in your library only.

ℹ

Sharing is part of the collaboration feature set and is available to every registered account (including the free plan). The Share item appears in the More menu only on pages that support sharing.

Creating a share link

  1. Open the document

    Open your document (or its snapshot) and choose More (⋯) → Share annotations.

  2. Set permissions

    Choose what recipients can do: view, annotate, reply, edit. View is pre-selected; mix and match the rest.

  3. Protect it (optional)

    Add a password so only people you share it with can open the link.

  4. Set an expiry

    Pick how long the link stays valid: 1, 3, 7, 15, or 30 days (7 by default). Once the link expires, it stops working.

  5. Share it

    Copy the link and send it. Recipients open it in any browser — no extension needed — and see the document with your annotations.

Managing shares

In the manager, Features → Shares lists everything you have shared, grouped by page, with filters for active and expired links. For each share you can:

  • Copy the link or open it yourself.
  • Edit permissions, password, and expiry (or keep the current values).
  • Regenerate a link — it gets a new address and the old one stops working immediately.
  • Disable a link temporarily or delete it — access stops immediately.
  • See how many people interacted with each share.

Replies from collaborators

When someone annotates or replies on a shared document, their contributions appear on the page itself the next time you open it — with the author's name. From there you can reply inline, keeping the whole discussion attached to the document. If a page contains annotations from other accounts that you want to claim as your own, the drawer's Claim All as Mine action reassigns every annotation on that page to you (one-way; applies to one page at a time).

Annotation tools on a shared page

Shares with annotate or edit permission open with the full annotation panel. On a computer it docks as a vertical toolbar on the right side of the page — draggable and minimizable — offering:

  • Drawing & marks — Arrow, Flag, Rectangle frame, Image rect, Freehand line, Text note, Element mark.
  • Text highlights — select text and tap a color in the popup bar; enable Auto and every selection highlights immediately.
  • Panel controls — line width, color, style, the 💬 popup toggle, the annotation list drawer, undo, and help.

Two limits: Page screenshot relies on the extension's capture channel and is unavailable on shared pages; a view-only share (no annotate/edit permission) shows no toolbar at all — recipients can read annotations and open note bubbles, and reply there if the share allows replies.

Annotating on mobile

Shared pages are fully usable on a phone — open the link in a mobile browser, no extension needed. The toolbar docks to the bottom of the screen and wraps onto multiple rows so every control stays visible; it keeps following the visible area as you pinch-zoom. Interactions are touch-first: draw with one finger, pan and zoom with two.

To fit touch, the mobile tool set is trimmed relative to the desktop panel:

  • Available tools — Arrow, Image rect, Freehand line, Text note, plus text highlights (press and drag to select text, then tap a color or the note button in the popup bar).
  • Not available for creating — Flag, Rectangle frame, Element mark, and Page screenshot. Existing marks of these kinds still render normally; you just can't add new ones from a phone.
  • Box Select Text (mobile only) — drag a rectangle around a passage and all the text inside it is selected in one go, then the usual style picker appears: tap a color to highlight the whole box as a single annotation. On a desktop, selecting text with a mouse is already one gesture, so this tool isn't needed there.

Everything else matches the desktop: the annotation list slides up from the bottom as a sheet overlaying the page, collapsed note popups leave a bubble icon you can tap to reopen, and popups stay within the screen as you move or resize them. View-only shares show no toolbar here either.
