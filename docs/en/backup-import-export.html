Backup, Import & Export

Take your annotations anywhere: full backups, per-page exports, incremental Markdown copies, and importing on another machine.

Exporting

All export options live in the manager's Features → Import / Export menu. You choose a target folder and a format — JSON, CSV, or Markdown on the free plan; Pro adds HTML.

  • Export current page — exports the annotations of the page you are viewing, together with its content.
  • Export all — a complete backup in one compressed file: folders, pages, annotations, tags, documents, snapshots, and images. Keep it somewhere safe; it can be fully restored.
  • Incremental export — writes your library as Markdown into a folder you choose, mirroring your folder structure. Run it again later and only new, changed, moved, or deleted items are updated — ideal for keeping an Obsidian vault or notes folder in sync with your highlights.

Importing

Features → Import / Export → Import accepts files exported by Sagitnote (JSON and compressed backups — including a full "Export all" file). You choose a strategy:

  • Skip existing (default) — only new annotations are imported; nothing already in your library is touched.
  • Overwrite — imported data replaces matching existing annotations.

After importing, folders, documents, and counts refresh automatically. A summary tells you how many annotations were inserted and how many were skipped.

💡

Moving to a new computer? Either run Export all and import it there, or — once you're signed in — simply sign in on the new machine and press Sync now.
