备份、导入与导出

把标注带去任何地方：完整备份、单页导出、增量 Markdown 副本，以及在另一台电脑导入。

导出

所有导出都在管理器的功能 → 导入导出菜单里。先选目标文件夹，再选格式——JSON、CSV 或 Markdown（免费版）；Pro 额外支持 HTML。

  • 导出当前页面 — 导出当前查看页面的标注及其内容。
  • 导出全部 — 一份完整备份压缩包：文件夹、页面、标注、标签、文档、快照与图片。妥善保存，之后可完整恢复。
  • 增量导出 — 把标注库以 Markdown 写入你选择的文件夹，并保持你的目录结构。以后再次运行时只更新新增、修改、移动或删除的部分——非常适合让 Obsidian 仓库或笔记文件夹与你的高亮保持同步。

导入

功能 → 导入导出 → 导入接受 Sagitnote 导出的文件（JSON 和压缩备份——包括"导出全部"的完整备份文件）。选择一种策略：

  • 跳过已有（默认）——只导入新的标注，库里已有的数据不受影响。
  • 覆盖——导入的数据替换对应的已有标注。

导入完成后，文件夹、文档与计数会自动刷新，并提示共导入、跳过了多少条标注。

💡

换新电脑？可以"导出全部 + 在新机导入"；如果使用支持同步的套餐，直接在新机登录同一账号并点立即同步即可。
