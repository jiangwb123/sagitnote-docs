自建文档

编写并排版自己的页面——支持表格、图片与公式——然后像网页一样标注和分享。

创建文档

文档在标注管理器中创建：功能菜单的新建文档、侧边栏文件夹标题栏的新建文档按钮都可以；右键任意文件夹还能直接在该文件夹内新建。用从图片新建文档可以把本地图片直接汇成一篇文档。保存后会在独立标签页打开富文本编辑器。

编辑器

编辑器是完整的富文本编辑器。除了基础排版（加粗、斜体、下划线、删除线、行内代码），还支持：

  • 标题（H1/H2）、对齐、有序/无序列表、引用与代码块。
  • 颜色——字色与背景高亮调色板。
  • 表格——网格选择插入；合并与管理单元格；拖拽调行高。
  • 图片——粘贴或拖入、按 URL 插入，或把网页图片嵌入文档（"保存图片到文档"）。
  • 数学公式——基于 KaTeX 的行内与独立公式，实时预览；双击公式可再次编辑。
  • 阅读排版——字体、行高与页面宽度。
  • 导入——从 PDF、Word（.docx）、Excel、HTML 或 Markdown 导入内容。

随时 Ctrl+S 保存；有未保存改动时关闭会请求确认。没有标题的文档保存为"未命名文档"，之后可随时改名。

文档就是可标注的页面

每个文档都有自己的网页地址。打开它，Sagitnote 控制面板就在那里：高亮句子、画箭头、写批注——与普通网页完全一样。文档（及其快照）还是可以通过链接分享给他人的内容。

大小与限额

套餐限制每日可创建的文档数量和单个文档的大小——文档过大时编辑器会在保存前提醒。以只读方式导入的文档无法再次编辑；需要修改请新建文档。
