默认快捷键

快捷键 = 一个修饰键（默认 Alt）+ 一个字母/数字键。它们在页面上的标注面板打开时生效。

按键功能
Alt + 1箭头
Alt + 2旗帜
Alt + 3图片矩形
Alt + 4页面截图
Alt + 5自由线条
Alt + 6文字批注
Alt + 7矩形框
Alt + 8元素标记
Alt + C循环切换调色板颜色
Alt + S循环切换高亮样式
Alt + A开/关自动高亮
Alt + D打开/关闭标注列表抽屉
Alt + E整个浏览器的标注总开关（无需面板，随时可用）
Ctrl / ⌘ + Z撤销刚创建的标注
Esc关闭弹窗、菜单和图片查看器
ℹ

在输入框里打字时快捷键不会触发，不会干扰写批注。

修改按键

打开设置 → 快捷键可以：

  • 把修饰键换成 Alt、Shift 或 Ctrl。
  • 给任意功能指定自己的按键（点输入框后按键；Backspace 清除）。
  • 一键恢复全部默认值。
