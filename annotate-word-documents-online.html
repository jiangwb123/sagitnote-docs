Step by Step

How to annotate a Word document online

Five steps, about ten minutes including install

  1. Install Sagitnote and sign up free

    Add the extension from the Chrome Web Store or Edge Add-ons and create a free account. The free tier includes every annotation tool.

  2. Import your Word file

    Open the Annotation Manager → New document → import your .docx. The import is semantic: headings, lists, tables, images, and inline formatting come across into an annotatable page. PDF, Excel, Markdown, and HTML import the same way.

  3. Annotate like on any web page

    The document opens with the full toolkit: five highlight styles, arrows, flags, boxes, freehand drawing, and text notes — each note can carry a comment and a color from your own palette. Annotations save with the document and sync across your devices.

  4. Share one link — with guardrails

    Create a share link and choose what reviewers can do: view, annotate, reply, or edit — combined freely. Add an optional password and a 1–30 day expiry. Disable the link any time; access stops instantly.

  5. Collect replies in place

    Reviewers open the link in any browser — no extension, no account, desktop or mobile. Their replies land right on the document next to your marks, so the discussion stays anchored to the sentence it's about.

The Point of It All

What your reviewer experiences

This is the part that decides whether a review round takes one email or five: the other side installs nothing and registers for nothing. They click a link and see your document — your highlights, arrows, and notes on the original text — and reply inline. On a phone, on a colleague's locked-down work laptop, on any browser: it just opens.

Compare the usual alternatives: Word's own comments require the reviewer to have Word (and often to sign in); Google Docs requires a Google account and an upload that reflows the layout; a PDF of screenshots loses the connection between comment and context. A shared Sagitnote page keeps the original text and the conversation in one place.

Honest Details

What the import preserves — and what it doesn't

Comes across cleanly

Headings and structure, bullet and numbered lists, tables (including merged cells), embedded images, bold/italic/underline, links, and colors. For reports, drafts, contracts, and specs — the documents people actually review — this is nearly everything.

Simplifies or drops

The conversion is semantic, not a pixel-perfect render: text boxes, multi-column layouts, headers/footers, footnotes, and tracked changes may reflow or simplify.

Need visual fidelity instead?

Export the Word file to PDF and open it with Sagitnote: the built-in PDF viewer renders pages exactly as they'll print, with all annotation tools on top. Many review flows do exactly this — Word route when the text matters, PDF route when the layout matters. PDF annotation details →

FAQ

Questions, answered

Can I annotate a Word document online for free?

Yes. Install the Sagitnote extension (Chrome or Edge), sign up free, import your .docx into a document, and annotate it with all ten tools — highlights, arrows, notes, freehand, and more. The free tier includes 3 new documents and 100 new annotations per day, which covers typical document review.

Do reviewers need to install anything or register?

No. When you share a document, reviewers open an ordinary link in any browser — desktop or phone. They can read, and (if you allow it) reply or annotate, without installing the extension or creating an account.

Where does my Word file go when I import it?

The imported content is stored locally in your browser first (local-first design), then synced to your own account on EU-hosted servers as a backup. It is not visible to anyone else unless you actively create a share link.

Does the import preserve Word formatting?

It preserves the content semantically: headings, lists, tables, images, and inline formatting come across. It is not a pixel-perfect render — very complex layouts, text boxes, headers/footers, and tracked changes may simplify. If visual fidelity matters more than editing, export the Word file to PDF and annotate the PDF instead.

Can my reviewer edit the document, and do I get a .docx back?

With edit permission, a reviewer can modify the shared document in their browser. Sagitnote documents export to Markdown, HTML, CSV, and JSON — there is no automatic .docx round-trip, so keep your original Word file as the source of record.
