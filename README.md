# Sagitnote — Docs & Website

Official documentation and public website content for **Sagitnote** (天箭批注), a full-featured web annotation browser extension for Chrome & Edge.

- 🌐 **Documentation (this site)**: https://jiangwb123.github.io/sagitnote-docs/ — English & 中文
- 🏠 **Product site**: https://www.webnoteshub.com
- 🧩 **Chrome Web Store**: https://chromewebstore.google.com/detail/sagitnote/llajphjgjgmplakjdjoaghojmgogghic
- 🧩 **Edge Add-ons**: https://microsoftedge.microsoft.com/addons/detail/nkepoeakeihkniefgjeofdfhmfmdaedd
- 📦 **Direct install (zip)**: [downloads/](downloads/) — latest official package
